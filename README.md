# Times Dash

A timed multiplication quiz for kids. Practice any tables from 1–12, race a clock, and save high scores on the device.

## Features

- Select one or many factors from 1–12
- Questions place the selected factor on either side of the multiplication
- Configurable time limit and question count (quiz ends when either is hit)
- Live score and timer while playing
- Typed answers with quick feedback
- Review missed questions after the round
- High scores stored in the browser (`localStorage`)

## Defaults

- All tables selected (1–12)
- 60 seconds
- 20 questions

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

```bash
npm i -g vercel
vercel
```

Or connect this GitHub repo in the Vercel dashboard and deploy the `main` / PR branch.
